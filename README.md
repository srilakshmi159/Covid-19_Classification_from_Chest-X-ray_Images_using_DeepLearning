# Covid-19_Classification_from_Chest-X-ray_Images_using_DeepLearning
Classifying COVID-19 from chest X-ray images using CNN deep learning

## Objective
Classify chest X-ray images into normal or abnormal using Convolutional Neural Networks (CNN).

## Dataset
- Kaggle Chest X-ray datasets
- Number of images: Large number of images
- Classes: Normal, Pneumonia

## Libraries/Tools
- Python(Anaconda distribution), TensorFlow/Keras, NumPy, Pandas, Matplotlib

## Workflow
1. Data preprocessing (resize, normalize, split train/test)
2. CNN model design and training
3. Model evaluation using accuracy and loss metrics
4. Visualization of results

## Results
- Achieved 83-94% accuracy on test set
- Confusion matrix shows model performance across classes

## Learning Outcomes
- Practical experience in building and training deep learning models
- Data handling and preprocessing
- Understanding of CNN architecture, activation functions, and optimization
- Visualization and interpretation of model results
